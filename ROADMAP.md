# Roadmap

1. Reduce pilot costs: check origin-based prices and obtain affordable local inbound
   access through a suitable number or SIP carrier. Keep paid tests deliberate.
2. Diagnose short-answer recognition and half-duplex turn boundaries with synthetic
   audio tests and privacy-preserving timing metrics. An LLM cannot fix dropped audio.
3. Add a language model behind typed extraction and confirmation gates, with Croatian
   paraphrase, negation, correction and ambiguity evaluations before live tests.
4. Complete conversational medication status, inventory and appointment operations
   using the existing domain tools. Distinguish a user report from verified action.
5. Test missed-call escalation with participating family contacts. Define behavior
   for voicemail, silence and answered-but-unconfirmed calls.
6. Add monitoring, backups, restore drills, retention, export and deletion.
7. Generalize family configuration and package a Windows setup wizard. Hosting remains
   required; family members only need an ordinary telephone.

## What the operator needs to provide

- A voice-capable inbound number with known carrier costs and provider configuration.
- An owned, verified number if using a separate outbound caller ID.
- Private credentials, hosting, DNS and approved family phone numbers.
- Medication schedules and initial inventory supplied by the family, not inferred by AI.
- A pilot test window, participating recipients and a small agreed spending limit.

Voice cloning and medical advice are outside this pilot's scope.
